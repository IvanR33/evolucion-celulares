# Evolución Hardware Móvil (1996 - 2002)

**Proyecto para la Unidad 2: Interacción con documentos HTML usando JavaScript** **Carrera:** Analista Programador | INACAP 2026  
**Estudiante:** Iván Ignacio Jiménez Reyes

Cronología técnica interactiva que detalla los hitos del hardware móvil. Este proyecto evoluciona de una maqueta estática a una aplicación dinámica mediante la manipulación del DOM y lógica de programación en JavaScript.

##  Tecnologías y Conceptos Aplicados

* **HTML5 & CSS3:** Estructura semántica avanzada y diseño Cyberpunk con variables CSS, efectos de resplandor neón y maquetación profesional.
* **JavaScript (Vanilla):** * Gestión dinámica de secciones (Single Page Application) para navegación sin recarga.
    * Manipulación del DOM (nodos y atributos) para la apertura de modales informativos.
    * Manejo de eventos de formulario y botones.
* **Estructuras de Datos:** Uso de **Objetos y Arreglos** para centralizar y organizar de manera eficiente la información técnica de los hitos móviles.

##  Registro de Consultas IA (Indicador de Evaluación N°7)

En cumplimiento con la pauta de evaluación, se documenta el apoyo de herramientas de IA durante el proceso:

1. **Optimización de Estructuras:** Se consultó sobre la mejor forma de organizar los datos de los teléfonos. La recomendación aplicada fue el uso de un **objeto centralizado** en JavaScript, lo que permite una mayor escalabilidad y limpieza del código (Criterio 2.1.3).
2. **Seguridad en Formularios:** Se aplicaron sugerencias para evitar el comportamiento por defecto de los formularios mediante `e.preventDefault()`, permitiendo una validación controlada por script antes del envío (Criterio 2.1.2).
3. **Interacción Dinámica:** La IA asistió en la lógica de las funciones para capturar atributos `data-` y renderizar dinámicamente el contenido de los modales, asegurando la reutilización de funciones (Criterio 2.1.4).
